Before trusting the collars

  1. Open each URL above on your phone (mobile data, not Wi-Fi) and check it shows the right dog.
  2. Write the URL to the NFC tag (e.g. the free “NFC Tools” app → Write → Add a record → URL).
  3. Scan each tag with an iPhone and an Android phone. Tap Call and WhatsApp on both — check the number and that the message names the right dog.
  4. Scan each printed QR code with a phone camera.
  5. Only then consider locking the tag (optional and permanent — a locked tag can never be rewritten).
  6. Keep the phone number engraved on the physical tag too: NFC only stores this link, it is not a GPS tracker, and a finder needs internet to open the page.
